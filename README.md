# Chocolate Night Shift v0.8

Open `index.html` in any modern browser. No installation or internet connection is required.

## Controls

- Desktop: WASD or arrow keys
- Mobile: on-screen joystick
- Weapons fire automatically
- Collect cyan cocoa beans to level up
- Survive the three-minute prototype shift

## Included

- Registration Marks orbit weapon
- Unlockable Cocoa Cannon
- Ribbon Whip and Molten Splash weapons
- Three enemy types
- Nine capped upgrade types with smarter card choices
- XP and level-up choices
- Steam-vent hazards
- Enemy knockback, damage numbers, particles, and wave announcements
- Detailed shift report with damage and final loadout
- Chris uses creator-supplied directional animations: four left frames, four right frames, two forward frames, and two away frames
- Chris always returns to the forward-facing idle artwork whenever movement stops
- Five creator-supplied 128×128 floor tiles arranged in a stable randomized pattern each shift
- Creator-supplied edge and corner tile artwork retained in the assets folder for future perimeter work
- Responsive desktop and mobile controls
- Victory, defeat, pause, and restart states
